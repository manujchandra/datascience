Custom Duration Returns

NIFTY/BANKNIFTY Custom Duration Return Analysis

This study analyses the returns of an instrument over a user specified time period. For example, if someone wants to know the returns generated over a period of 7 days, or any other time period, the app can dynamically calculate the same.

Historical Max Runs

NIFTY/BANKNIFTY Historical Max Runs Analysis

This is a range analysis study. It calculates the maximum advances and declines of an instrument over a period specified by the user and generates meaningful charts and analysis to help project future price targets.

Weekday Returns

NIFTY/BANKNIFTY Weekday Returns Analysis

Usually when we analyse an instrument, we do so on a daily, weekly, monthly or yearly basis. Here I attempted to create a tool to analyse an underlying on a weekday basis. This tool proved helpful especially for intraday traders who want to maximize their probability of winning a trade.

Index Price Forecast

NIFTY/BANKNIFTY Price Forecast Study

This tool demonstrates a tool that could be useful for Option Traders. This is a price range forecast tool for NIFTY and BANKNIFTY. The user can choose the training period and the forecast period. The tool also helps in calculating the probability of price closing between any two price points. Watch the video to learn more features.
